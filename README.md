# Student Task Manager

A responsive web application designed to help students organize, manage, and track their academic tasks efficiently.

## Features

- Add and delete tasks
- Set task priorities
- Search and filter tasks
- Mark tasks as completed
- Due-date tracking
- Progress tracking
- Task statistics
- LocalStorage persistence
- Dark/light mode
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run

1. Download or clone this repository.
2. Open `Index.html` in a web browser.

## Project Overview

This project was developed to provide students with a simple and interactive way to manage academic tasks while practicing front-end web development and JavaScript programming.
